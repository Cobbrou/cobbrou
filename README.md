## Projects

| Project | Description |
|---|---|
| [RestoFlow](https://github.com/Cobbrou/RestoFlow) | A real-time point-of-sale and orchestration app for restaurants, connecting the floor, the kitchen display and the back-office, even offline. Built with React 19, NestJS, Prisma, Socket.IO and Tailwind, as an installable PWA. |
| [Allure](https://github.com/Cobbrou/Allure) | An open-source, local-first Strava-inspired app to record, analyze and share runs, rides and hikes, with live GPS recording, training analysis, route building and sharing. Built with React, Vite, MapLibre and Capacitor (Android). *Early development.* |
| [DISPATCH-17](https://github.com/Cobbrou/DispatcherFR) | A French dispatch-room simulator (CAD) inspired by gendarmerie operations: take 17 calls, fill in incident reports, send patrols on a dark map and handle unexpected events. Built with React 19, TypeScript, Vite, Tailwind, Leaflet and Zustand. *In progress.* |
| [Freenary](https://github.com/Cobbrou/freenary) | Fork of [suiramdev/freenary](https://github.com/suiramdev/freenary), an open-source, self-hosted personal finance app. |
| [Schoolmouv Scraper](https://github.com/suiramdev/schoolmouv_scrapper) | A Python bot to download Schoolmouv lessons |
| [Stock Manager](https://github.com/Cobbrou/stockManager) | A Python script to manage a shop's stock |
